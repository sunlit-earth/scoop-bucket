# Sunlit Earth for Scoop

The [Scoop](https://scoop.sh) bucket for [Sunlit Earth](https://github.com/sunlit-earth/sunlit-earth), a view of Earth as seen from space as your wallpaper.

```powershell
scoop bucket add sunlit-earth https://github.com/sunlit-earth/scoop-bucket
scoop install sunlit-earth/sunlit-earth
```

`scoop update sunlit-earth` upgrades it, and `scoop uninstall sunlit-earth` removes it. Your settings in `%LOCALAPPDATA%\SunlitEarth` are kept.

The manifest is written by the release pipeline of the main repository on every stable release. Please do not edit it by hand, and report problems at https://github.com/sunlit-earth/sunlit-earth/issues.
